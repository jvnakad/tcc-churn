# TCC - B2B Customer Churn Prediction

Machine learning model to predict customer churn for a B2B company, built with Orange Data Mining.

## Dataset
- 47 B2B customers
- 6 months of purchase history
- Binary target: churn (yes/no) based on 15-day inactivity threshold

## Model
- Algorithm: Logistic Regression
- Evaluation: Random Sampling (20x, 75/25 split)
- Accuracy: 82.5% | AUC: 0.877

## Tools
- Orange Data Mining
- Excel Power Query
